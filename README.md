# Diego Multimarcas

Protótipo de apresentação da Diego Multimarcas, em Lajeado/RS.

Site estático com seleção de Hilux, favoritos locais, contato por WhatsApp e mapa interativo da loja.

As referências do catálogo não confirmam estoque atual. Valores e especificações devem ser confirmados com a loja. A imagem de campanha é ilustrativa, gerada por IA. A fachada recebeu tratamento visual com IA a partir de imagem fornecida; fonte Google Street View.

O mapa utiliza Leaflet e OpenStreetMap com atribuição. Imagens e identidade visual são utilizadas no contexto deste protótipo.

Para executar localmente: `python -m http.server 4174`.
